# 0002. 定義は Go で書き、言語に依存しないマニフェストに書き出す

- 状態: 承認
- 日付: 2026-11-02
- 関連: [design.md](../design.md) 2.2、3章

## 背景

主な言語は Go にしたい。一方で、Go 以外のサービスにも広げられる余地を残したい。

## 決定

- 定義は Go の DSL で書く。型・ハンドラー・公開の許可が同じ場所にあり、コンパイラが食い違いを検出できる
- 定義は JSON / YAML のマニフェストに書き出せる。マニフェストが公開範囲・プロトコル・フィールドの公開範囲・認可の宣言をすべて持つ
- 契約ファイルの生成と実行時の判断は、マニフェストだけを見る。Go 以外のチームはマニフェストを直接書いてよい

## 結果

- Go では型安全に書け、ほかの言語へはマニフェストを境界に広げられる
- マニフェストの形式が公開する契約になり、版と互換性を管理する必要がある（未決）

## 検討した代替案

- YAML や TypeSpec のスキーマだけを正にする：言語に依存しないが、Go のハンドラーとの食い違いを実行時まで検出できない
- Go の定義だけ：ほかの言語に広げる道が無い
