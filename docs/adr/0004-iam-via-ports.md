# 0004. 認証・認可は iam にポート経由で任せる

- 状態: 承認
- 日付: 2026-11-02
- 関連: [design.md](../design.md) 6章

## 背景

認証・認可は [imohiyoko/iam](https://github.com/imohiyoko/iam) を主に使う。iam のアクセストークンは不透明で、イントロスペクションで確かめる（iam ADR 0021）。

## 決定

- 認証は iam のイントロスペクション、認可は `/v1/admin/authz:check` で行う
- 依存はポート（`port.Authenticator`、`port.Authorizer`）に閉じ、iam の実装はアダプタに置く。テスト用にインメモリの実装を持つ
- 足りない機能は iam に issue で求める（iam#151〜#154）

## 結果

- 認可の規則はこのライブラリに持たず、iam の1か所で管理できる
- 要求ごとに iam への問い合わせが入る（iam の保証値以内のキャッシュで抑える）

## 検討した代替案

- このライブラリで JWT を自前で検証する：iam のトークンは不透明で、失効も即時に反映できない
